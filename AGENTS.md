# AGENTS.md

## Project

Documentation site for **OtO** teleprompter software. SvelteKit + SveltePress (`@sveltepress/vite` + `@sveltepress/theme-default`), deployed to Vercel via `@sveltejs/adapter-vercel`. All pages are prerendered.

## Commands

- `pnpm dev` — dev server
- `pnpm build` — production build (prerenders all pages + generates search index)
- `pnpm check` — `svelte-kit sync && svelte-check` (type checking)
- No lint, formatter, or test runner is configured.

Run `pnpm check` after changes. There is no lint or test step.

## Svelte Version

**Svelte 5** — Uses runes (`$state`, `$derived`, `$effect`, `$props()`) and Svelte 5 syntax. All components use the new patterns.

## Vite Config

`vite.config.js` is the only config. Includes:
- `sveltepress()` plugin with `defaultTheme()` for navbar, sidebar, search
- `mdContent()` custom plugin for search index generation
- `$img` alias for SVG imports

## Content Structure

Docs live under `src/routes/docs/` with three top-level groups:

```
src/routes/docs/
  oto-basics/     # Getting started, licensing, editing, rundown, prompting, controllers
  markers/         # Standard markers, action markers, network markers, PPT setup
  advanced/        # Shortcuts, overlays, network, FAQ, example setups
```

Each leaf is a `+page.md` file with YAML frontmatter including `title` and `order` fields. SveltePress auto-generates the sidebar using the `order` frontmatter.

## Custom Markdown Components

Located in `src/lib/components/md/` and imported in each `+page.md` that uses them:
- `Icon.svelte` — SVG icon component (48 uses across 9 files)
- `Number.svelte` — Numbered callout badges with tooltip (49 uses)
- `Q.svelte` — Marker/type display badges (5 uses)
- `TextIcon.svelte` — Text with inline icon (12 uses)
- `Round.svelte` — Colored dot indicators (6 uses)
- `ImageZoom.svelte` — Zoomable image (1 use)
- `SvgSchemas.svelte` — SVG diagram renderer (3 uses)
- `Steps.svelte` / `Step.svelte` — Numbered step list (2 files)

Components are imported via `<script>` blocks at the top of each markdown file.

## Admonitions

Uses SveltePress admonition syntax: `:::tip[Title]`, `:::info[Title]`, `:::warning[Title]`.

## Search

`mdContent.js` is a custom Vite plugin that runs at `buildEnd`. It reads all `.md` files under `src/routes/docs/`, strips custom components/syntax, and writes a JSON search index to `src/routes/search.json/posts.json`. The `Search.svelte` component uses FlexSearch to provide client-side search.

## Key Details

- Package manager: **pnpm** (lockfile present, `.npmrc` with `engine-strict=true`)
- Root path `/` redirects to `/docs/oto-basics/get-started`
- Sidebar is auto-generated by SveltePress from directory structure + `order` frontmatter
- `$lib` alias points to `src/lib/`
- `$img` alias points to `src/img/`
- `MARKETING.md` and `TECHNICAL.md` at root are reference material, not served by the site
